# NextSignal — Signal to Roadmap

**[Open the interactive demo →](https://poojaahegde.github.io/signal-to-roadmap/)**

Turn customer feedback into a traceable Now / Next / Later roadmap. This portfolio demo starts with fictional feedback and runs entirely in your browser.

1. Open the sample workspace and add or import sample CSV/TXT feedback.
2. Review keyword-based suggestions and build your roadmap.
3. Edit cards, change lanes, inspect source feedback, and export your plan.

Changes stay in browser storage. **Reset sample** restores the fictional workspace. Use fictional data when exploring.

## Hosting and privacy

The [public demo files](docs/) run on GitHub Pages. The demo has no sign-in, Supabase connection, API keys, or analytics. Files are read locally and feedback is never uploaded. The former Cloudflare deployment has been removed.

Grouping uses keyword rules. Suggested priorities are starting points for human review. Counts represent feedback records rather than unique customers.
