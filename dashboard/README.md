# Signal to Roadmap app

Live website: https://signal-to-roadmap.pages.dev/

React + TypeScript + Vite. Free guest feedback/roadmap mode; email-authenticated private company workspaces and multiple products via Supabase.

See [SETUP.md](SETUP.md) for configuration, privacy boundaries and current limitations. Run `npm install`, `npm run dev`, or `npm run build`. Run `node check.mjs` for the mocked cloud and grouping checks.

The public `.env.production` configuration contains a publishable browser key only. Never add SMTP passwords or service-role credentials to frontend code.
